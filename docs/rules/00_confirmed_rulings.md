# Kizuna — Confirmed Rulings

Rulings confirmed by Priya on 16 November 2026. Where these differ from, or settle an ambiguity in, the other files in this folder, these win.

| Topic | Ruling |
| --- | --- |
| Turn order | After East discards, play passes to the player on East's right and continues anticlockwise round the table. |
| Sheung | Claimed only from the player who plays immediately before you. |
| Win on a discard | Only the discarder pays the winner. |
| Win by self-pick | All three players each pay the winner the full hand value. |
| Self-pick bonus | +2 points (not the +3 tournament-card value). |
| Self-pick from the Flower Wall | +5 points (not the +10 tournament-card value). |
| Drawn-game pot | Each player adds 5 points (not 3). |
